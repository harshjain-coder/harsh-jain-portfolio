# Harsh Jain Portfolio

## Files
- index.html — complete portfolio (HTML + CSS + JavaScript in one file)
- Harsh_Jain_Resume.pdf — resume linked from the portfolio

## Before publishing
Open `index.html` and replace the placeholder `#` links for:
- Job Portal Live API
- Social Sphere Live API
- Expense Tracker GitHub + Live API
- Task Management GitHub + Live API

The first two GitHub links are already filled from your resume/project information.

## Run locally
Double-click `index.html` or open it with VS Code + Live Server.

## Publish
Upload the folder to GitHub and enable GitHub Pages, or deploy the folder on Netlify/Vercel.
